Getting started

Test a Slack app against Slack in Worlds at slack.makeworlds.dev.

Point your app at a world

Use the world as your Slack base URL. With @slack/web-api:

const client = new WebClient(token, {
  slackApiUrl: "https://slack.makeworlds.dev/api/",
});

Install your app

Send users to /oauth/v2/authorize on the world instead of slack.com. The callback hands your app a code, and oauth.v2.access exchanges it for a bot token as usual.

Receive events

The world posts event callbacks to your events URL, signed with your signing secret. A non-2xx response, a connection failure or no answer within 3 seconds is retried with X-Slack-Retry-Num right away, after 1 minute and after 5 minutes.

Admin API

Admin routes take Authorization: Bearer <admin token>.

  • POST /_worlds/reset restores the seed.
  • POST /_worlds/slack/redirect-uris registers an OAuth redirect URI.
  • GET /_worlds/slack/state returns users, channels and messages.
  • POST /_worlds/slack/act calls a Web API method as a user, e.g. to post an @mention.
